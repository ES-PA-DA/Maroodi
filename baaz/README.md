**Baaz: Price recording app (v0.01-beta)**

**CAUTION IS A MVP NEEDS IMPROVEMENTS**

**To test:**
1. Clone project
2. npm install
3. npx expo start
4. Open in Expo Go (Playstore App)

**Current state:**
- CRUD stores
- CRUD products (linked to a store)
- CRUD prices (linked to a product)

**Roadmap:**
- Refactor in workflow
- Update prices
- Add images to stores and products.
- Implement search in stores and products screens.
- Success and Error alerts.
- Refresh (updated) stores, products and prices lists when new one is added.
- And more...
